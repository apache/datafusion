# Upgrade Guides

## DataFusion 57.0.0

### `COPY TO` ordering

`COPY TO` no longer guarantees preservation of its input's ordering. Add an
explicit `ORDER BY` when output order matters.

Previously, if `t` had an existing output ordering of `ORDER BY c1`, the `COPY TO`
statement could infer and maintain that order in the written file.

```txt
COPY (SELECT * FROM t) TO 'ordered.parquet';
```

Now, an explicit `ORDER BY c1` clause is required to preserve this behavior. In
this case, no extra sorting is needed during execution; this is a syntax change
that aligns with the SQL specification.

```txt
COPY (SELECT * FROM t ORDER BY c1) TO 'ordered.parquet';
```
