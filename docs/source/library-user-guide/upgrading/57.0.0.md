# Upgrade Guides

## DataFusion 57.0.0

**Note:** DataFusion `57.0.0` has not been released yet. The information provided
in this section pertains to features and changes that have already been merged
to the main branch and are awaiting release in this version.

### `array_sum` returns integer and decimal types

`array_sum` (and its alias `list_sum`) previously cast every element to
`Float64` and returned `Float64`, so integer sums above 2^53 and decimal sums
lost precision. The result type now follows the `sum` aggregate function:

| Element type                          | Result type                     |
| ------------------------------------- | ------------------------------- |
| `Int8`, `Int16`, `Int32`, `Int64`     | `Int64`                         |
| `UInt8`, `UInt16`, `UInt32`, `UInt64` | `UInt64`                        |
| `DecimalN(p, s)`                      | `DecimalN(min(p + 10, max), s)` |
| any other type                        | `Float64` (unchanged)           |

Integer sums now wrap on overflow, as `sum` does. To keep the previous
`Float64` result, cast it: `arrow_cast(array_sum(col), 'Float64')`.
