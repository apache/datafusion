# Upgrade Guides

## DataFusion 57.0.0

**Note:** DataFusion `57.0.0` has not been released yet. The information provided
in this section pertains to features and changes that have already been merged
to the main branch and are awaiting release in this version.

### `PhysicalExtensionCodec` can decode with the full decode context

`PhysicalExtensionCodec::try_decode` takes a `TaskContext`, which does not carry
the state that only exists while the surrounding plan is being decoded. The
trait gains `try_decode_with_ctx`, which takes the `PhysicalPlanDecodeContext`
that decode is running under. See [issue #25089] for details.

**Who is affected:**

- No changes are required. `try_decode_with_ctx` defaults to calling
  `try_decode` with `ctx.task_ctx()`.
- If you need the additional context, implement `try_decode_with_ctx` and pass
  `ctx` on to any nested decode.

[issue #25089]: https://github.com/apache/datafusion/issues/25089
