# Upgrade Guides

## DataFusion 56.0.0

### Hive null partition directories are read as NULL

`ListingTable` now reads a partition directory named
`__HIVE_DEFAULT_PARTITION__`, for example `/table/d=__HIVE_DEFAULT_PARTITION__/`,
as a NULL partition value. This is the placeholder Hive compliant writers use for
a null partition value, and matches how Hive, Spark and Impala read it.
Previously the directory name was parsed as the partition column's type, which
failed for non-string columns and returned the literal string
`__HIVE_DEFAULT_PARTITION__` for string columns.

The placeholder is set by the new
`datafusion.execution.listing_table_hive_default_partition_name` option, the
equivalent of Hive's `hive.exec.default.partition.name`. Setting it to the empty
string reads the directory name as the value, as before.

Partitioned writes (`INSERT INTO` and `COPY ... PARTITIONED BY`) now reject a
partition value equal to this placeholder, since it would be read back as NULL.

To support this, `ListingTable` now declares all partition columns as nullable,
so `DESCRIBE` and the table schema report them as nullable.

**Who is affected:**

- Tables with string partition columns that contain a
  `__HIVE_DEFAULT_PARTITION__` directory. Its rows now have a NULL partition
  value, so `WHERE col = '__HIVE_DEFAULT_PARTITION__'` no longer matches them.
- Partitioned writes of the value `__HIVE_DEFAULT_PARTITION__`, which now
  return an error instead of writing a directory that reads back as NULL.
- Code that relies on `ListingTable` partition columns being non-nullable.
- Callers of `pruned_partition_list`, which can now return files with NULL
  partition values. Partition fields built from its output must be nullable.
- Users constructing `ExecutionOptions` (or `ConfigOptions`) with an exhaustive
  struct literal must provide the new
  `listing_table_hive_default_partition_name: String` field.

**Migration guide:**

Select the null partition with `IS NULL`:

```sql
SELECT * FROM t WHERE col IS NULL;
```

To keep reading and writing `__HIVE_DEFAULT_PARTITION__` as a literal value,
disable the mapping:

```sql
SET datafusion.execution.listing_table_hive_default_partition_name = '';
```

If your writer uses a different `hive.exec.default.partition.name`, set the
option to that name instead:

```rust,ignore
let mut config = SessionConfig::new();
config
    .options_mut()
    .execution
    .listing_table_hive_default_partition_name = "MY_NULL".to_string();
```
