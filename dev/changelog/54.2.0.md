# Apache DataFusion 54.2.0 Changelog

This release consists of 6 commits from 4 contributors. See credits at the end of this changelog for more information.

See the [upgrade guide](https://datafusion.apache.org/library-user-guide/upgrading.html) for information on how to upgrade from previous versions.

**Breaking changes:**

- [branch-54] fix: read Hive's null partition placeholder as NULL (backport #26310) [#27308](https://github.com/apache/datafusion/pull/27308) (hareshkh)

**Other:**

- [branch-54] fix: prevent LEAD/LAG IGNORE NULLS panic without null bitmap (#23706) [#26319](https://github.com/apache/datafusion/pull/26319) (lilic)
- [branch-54] fix: keep a CoalescePartitionsExec required by a SinglePartition child [#26961](https://github.com/apache/datafusion/pull/26961) (hareshkh)
- [branch-54] Expand scalar async UDF results to the batch row count (#25828) [#27372](https://github.com/apache/datafusion/pull/27372) (kamilk-pal)
- [branch-54] fix(smj): handle floating-point keys across batch boundaries (#25134) [#27357](https://github.com/apache/datafusion/pull/27357) (Sunninsky)
- [branch-54] fix: allow NULL-padded rows in sort-merge join filter evaluation (#26027) [#27356](https://github.com/apache/datafusion/pull/27356) (Sunninsky)
