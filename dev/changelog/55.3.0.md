# Apache DataFusion 55.3.0 Changelog

This release consists of 11 commits from 4 contributors. See credits at the end of this changelog for more information.

See the [upgrade guide](https://datafusion.apache.org/library-user-guide/upgrading.html) for information on how to upgrade from previous versions.

**Other:**

- [branch-55] fix: frame IPC messages when reading spill files so batches pin only their own bytes (#24592) [#26435](https://github.com/apache/datafusion/pull/26435) (andygrove)
- [branch-55] perf: Avoid copying when materializing output in OrderedPartialAggregateStream (#25312) [#25843](https://github.com/apache/datafusion/pull/25843) (andygrove)
- [branch-55] Fix retained-capacity accounting for grouped byte MIN/MAX (#26154) [#26767](https://github.com/apache/datafusion/pull/26767) (andygrove)
- [branch-55] fix: prevent unsafe integer interval propagation (#25234) [#26869](https://github.com/apache/datafusion/pull/26869) (haohuaijin)
- [branch-55] fix: restrict reverse cast constraint propagation to safe conversions (#25531) [#26870](https://github.com/apache/datafusion/pull/26870) (haohuaijin)
- [branch-55] fix(smj): handle floating-point keys across batch boundaries (#25134) [#27353](https://github.com/apache/datafusion/pull/27353) (Sunninsky)
- [branch-55] fix: allow NULL-padded rows in sort-merge join filter evaluation (#26027) [#27354](https://github.com/apache/datafusion/pull/27354) (Sunninsky)
- [branch-55] fix: ensure deferred-filtered outer joins preserve streamed output order (#24573) [#27358](https://github.com/apache/datafusion/pull/27358) (Sunninsky)
- [branch-55] fix: correct `LEAD/LAG IGNORE NULLS` evaluation and limit pushdown (#25472) [#27320](https://github.com/apache/datafusion/pull/27320) (Sunninsky)
